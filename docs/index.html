产品介绍

详情页图片整理，不该这么麻烦

运营、美工、选品同学每天都要保存商品图。右键一张张存、格式五花八门、图标广告混杂——图提取把这些琐事交给插件完成。

图片分散难找

主图、详情长图、规格图散落在页面各处，滚动查找费时费力。插件自动扫描详情页，把可用图片集中到一个预览页。

无法批量保存

浏览器右键只能单张下载。图提取支持勾选多张后一键批量下载，文件自动编号，适合归档与二次设计。

格式不统一

电商 CDN 常返回 JPG、WebP 等格式。下载时统一转换为 PNG，方便本地编辑、印刷与素材库管理。

核心功能

从提取到下载，一步到位

六个关键能力覆盖完整工作流：扫描、过滤、预览、勾选、转码、批量保存。

一键提取

详情页右下角点击「获取图片」，自动收集 img、懒加载与背景图资源。

智能过滤

过滤 logo、图标、占位图及过小图片，减少噪声，留下真正有用的商品图。

集中预览

新标签页网格展示全部候选图，来源页面信息一目了然，方便快速核对。

自由勾选

默认全选，支持单选、全选、反选，只下载你需要的那几张，灵活可控。

统一 PNG

后台将 JPG / WebP 等格式转为 PNG，命名规范，便于后续设计与归档。

批量下载

一键下载选中图片至浏览器默认目录，进度可见；个别失败不影响其余。

安装步骤

四步完成本地加载

当前以开发者模式加载未打包扩展。按下列步骤操作即可在 Chrome 中启用图提取。

  1. 1

    下载插件压缩包并解压

    获取项目压缩包后解压到本地任意目录，记住解压出的文件夹路径（例如 imagegrab）。

  2. 2

    打开 Chrome 扩展管理页

    在地址栏输入 chrome://extensions 并回车，进入扩展程序管理页面。

  3. 3

    打开「开发者模式」

    点击页面右上角的 开发者模式 开关，打开后会出现「加载已解压的扩展程序」按钮。

  4. 4

    加载已解压的扩展程序

    点击 加载已解压的扩展程序，选择刚才解压的插件文件夹，确认扩展已启用即可。

开始用图提取整理商品图

安装后打开淘宝、京东或拼多多商家版详情页，点击右下角「获取图片」即可体验完整流程。
